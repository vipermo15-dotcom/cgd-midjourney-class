에디터-실습가이드와 함께 사용하세요. 아래는 Edit 탭에서 이미지를 불러온 뒤 각 도구별로 입력하는 프롬프트 예시입니다.

ED-01

제품 컬러 베리에이션 (Paint · Erase)

상황: 상세페이지용 제품 목업에서 색상만 다르게 여러 벌 만들고 싶을 때

  1. 01
    제품 부분만 Erase로 마스킹
  2. 02
    새 프롬프트 입력
the same product in a deep forest green color, matte finish, same lighting and angle

색상만 바꿔 2~3벌 더 반복 (sage green, terracotta 등)

ED-02

배경만 브랜드 컬러로 교체 (Smart Select)

상황: 인물/제품 사진에서 배경만 브랜드 톤으로 통일하고 싶을 때

  1. 01
    Smart Select로 인물(또는 제품) 클릭 → 자동 선택
  2. 02
    "erase background" 적용
  3. 03
    새 프롬프트 입력
soft cream and forest green gradient studio background, warm even lighting
ED-03

스케치를 완성 렌더링으로 전환 (Retexture)

상황: 러프 스케치나 라인 드로잉을 채색된 최종 결과물처럼 보여주고 싶을 때

  1. 01
    스케치 이미지를 Edit from URL 또는 업로드로 불러오기
  2. 02
    Retexture 탭 선택 후 프롬프트 입력
fully rendered digital illustration, soft painterly shading, warm color palette,
keep the same composition and linework structure

특정 화풍을 원하면 참고 이미지를 스타일 레퍼런스로 함께 추가

ED-04

세로형 이미지를 가로형으로 확장 (Move/Resize)

상황: 정사각형·세로형으로 만든 이미지를 웹 배너(16:9)로 재활용하고 싶을 때

  1. 01
    Move/Resize 선택 → 캔버스를 좌우로 드래그해 확장
  2. 02
    비율 입력란에 16:9 입력
  3. 03
    필요시 확장 방향 프롬프트 추가
extend the scene naturally to both sides, same lighting and color tone
ED-05

소재 교체 (Retexture)

상황: 브랜딩 목업에서 재질만 바꿔 여러 톤을 제안하고 싶을 때

  1. 01
    목업 이미지를 불러온 뒤 Retexture 선택
  2. 02
    프롬프트 입력
matte ceramic texture instead of glass, soft natural highlights, same shape and composition

glass → frosted glass, brushed metal 등으로 바꿔 여러 소재 버전 제작

Reference도구 빠른 참고

목적도구
특정 영역만 다른 것으로 교체Paint (Erase) + 새 프롬프트
오브젝트 자동 선택 후 배경만 교체Smart Select → erase background
구도 유지하고 질감/화풍만 전환Retexture
캔버스 확장·비율 변경 (아웃페인팅)Move/Resize
여러 이미지를 합성Layers

Guide실습 순서

  1. 01
    위 5개 중 자신의 포트폴리오 작업과 가까운 것을 골라 에디터-실습가이드의 접근 방법대로 이미지를 불러옵니다.
  2. 02
    프롬프트의 색상·질감·스타일 단어를 자신의 프로젝트에 맞게 바꿔 적용합니다.
  3. 03
    결과 4개 중 1개를 선택해 저장하고, 가이드의 제출 체크리스트에 따라 제출합니다.
