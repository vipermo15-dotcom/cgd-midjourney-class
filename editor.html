미드저니 에디터(Editor) 실습 가이드

서울시기술교육원 컴퓨터그래픽디자인과 · 심화 실습 (부분 수정·합성)
실습워크북을 먼저 끝낸 뒤 진행하세요.
기준: Midjourney Editor (버전 무관 — v8.2로 만든 이미지도, v6/v7로 만든 이미지도 편집 가능)

Concept에디터(Editor)란?

지금까지는 프롬프트로 이미지를 "처음부터" 생성했다면, 에디터는 이미 만든(또는 업로드한) 이미지의 일부만 골라 고치는 도구입니다. 전체를 다시 생성하지 않고 원하는 부분만 지우고 다시 그리거나, 캔버스를 넓히거나, 표면 질감만 바꿀 수 있습니다.

포트폴리오에서 언제 쓰나요? 목업의 제품 색상 베리에이션 · 배경만 브랜드 컬러로 교체 · 매체 규격에 맞춘 캔버스 확장 · 스케치를 완성 렌더링으로 전환

Guide접근 방법

  1. 01
    midjourney.com 상단 메뉴에서 Edit 탭으로 이동합니다.
  2. 02
    Edit from URL(기존 이미지 링크) 또는 Edit Uploaded Image(파일 업로드)로 이미지를 불러옵니다.
  3. 03
    Create/Organize에서 바로 열면 라이트 버전(기본 기능만)입니다. 전체 기능은 반드시 Edit 탭에서 시작하세요.

Concept도구 5가지

도구기능언제 쓰나
Move / Resize캔버스 이동·확장, 비율 변경 (아웃페인팅)여백을 AI가 어울리게 채워 화면을 넓힐 때
Paint — Erase브러시로 바꾸고 싶은 영역을 지움(마스킹)특정 부분만 다시 그리고 싶을 때
Paint — Restore지운 영역을 원본으로 복원마스킹을 잘못했을 때
Smart Select클릭 한 번으로 오브젝트 자동 선택정교한 형태를 손으로 칠하기 번거로울 때
Retexture구도·형태 유지, 표면 질감·스타일만 재생성소재·화풍만 바꾸고 싶을 때

GuidePaint(Erase)로 부분 수정하기

  1. 01
    편집할 이미지를 불러옵니다.
  2. 02
    좌측 패널에서 Paint → Erase를 선택합니다.
  3. 03
    Brush Size로 크기를 조절하며 바꾸고 싶은 영역을 칠해 지웁니다.
  4. 04
    상단 프롬프트 입력창에 그 자리에 나타날 내용을 새 프롬프트로 입력합니다.
  5. 05
    Submit Edit을 누르면 4개의 결과가 생성됩니다.
  6. 06
    마음에 드는 결과를 Upscale to Create Page 또는 Download Image로 저장합니다.

GuideSmart Select로 정교하게 선택하기

  1. 01
    Smart Select를 클릭한 뒤, 바꾸고 싶은 오브젝트를 클릭합니다.
  2. 02
    AI가 형태를 자동 인식해 선택 영역(마스크)을 만듭니다.
  3. 03
    Include로 넓히거나 Exclude로 제외할 부분을 뺍니다. (예: 신발 선택 시 밑창 제외)
  4. 04
    Erase 후 상단 프롬프트로 새 내용을 입력해 생성합니다.
  5. 05
    배경만 바꾸려면 오브젝트를 선택한 뒤 "erase background"로 배경만 지우고 재생성합니다.

GuideRetexture로 스타일만 바꾸기

  1. 01
    이미지를 불러온 뒤 상단 탭에서 Retexture를 선택합니다.
  2. 02
    구조는 그대로 두고 바뀌길 원하는 재질·스타일을 프롬프트로 입력합니다.
  3. 03
    특정 화풍을 원하면 텍스트만으로 부족할 수 있습니다. 스타일 레퍼런스 이미지를 함께 넣으면 훨씬 정확합니다.
  4. 04
    결과 4개 중 원하는 톤을 선택합니다.

GuideMove/Resize로 캔버스 확장하기 (아웃페인팅)

  1. 01
    Move/Resize를 선택합니다.
  2. 02
    캔버스 가장자리를 드래그하거나 비율 입력란에 원하는 비율을 직접 입력합니다.
  3. 03
    새로 생긴 빈 공간이 원본과 자연스럽게 이어지도록 AI가 채웁니다.
  4. 04
    필요하면 프롬프트를 추가로 입력해 확장 방향을 유도할 수 있습니다.

  • 제품 사진에서 배경만 브랜드 컬러로 바꾸고 제품은 그대로 두고 싶다 → ______________
  • 완성된 일러스트의 구도는 그대로 두고 수채화 느낌으로만 바꾸고 싶다 → ______________

실습 01Paint(Erase)로 부분 교체하기

목표 · 특정 요소 하나를 다른 것으로 교체 
편집할 원본 이미지: ______________________
지운 영역: ______________________
새 프롬프트: ______________________
  • Erase로 정확한 영역만 마스킹했는가
  • 새 프롬프트가 주변 톤과 자연스럽게 어울리는 결과를 만들었는가

실습 02Smart Select로 배경만 교체하기

목표 · 제품/인물은 유지, 배경만 다른 톤으로 
선택한 오브젝트: ______________________
배경 교체 프롬프트: ______________________
  • Include/Exclude로 선택 범위를 정교하게 조정해봤는가
  • 오브젝트 형태가 훼손되지 않고 배경만 바뀌었는가

실습 03Retexture로 스타일 전환하기

목표 · 같은 구도, 다른 질감/화풍 
원본 이미지: ______________________
전환할 재질/스타일: ______________________
  • 원본과 결과의 구도가 동일하게 유지되었는가
  • 스타일 레퍼런스 이미지 유무에 따른 차이를 비교했는가

심화 · 선택Move/Resize로 매체 규격 확장하기

포트폴리오용 이미지 1장을 다른 매체 규격(정사각 → 16:9)으로 확장해보세요.

원본 비율: ______________________ → 확장할 비율: ______________________
  • 확장된 영역이 원본과 자연스럽게 이어지는가

Tip팁 & 주의사항

  • 편집 결과는 매번 4개씩 생성됩니다. 마음에 드는 결과는 반드시 갤러리에 저장하세요. 저장하지 않으면 시간이 지나 사라질 수 있습니다.
  • Smart Select는 배경과 대비가 명확한 이미지에서 더 정확하게 작동합니다.
  • Retexture로 특정 작가·화풍을 재현하려면 텍스트만으로는 한계가 있습니다. 스타일 레퍼런스 이미지를 함께 사용하세요.
  • Move/Resize 아웃페인팅은 한 번에 크게 확장하지 말고 단계적으로 넓히면 결과가 더 자연스럽습니다.
  • 라이트 에디터에는 레이어·리텍스처가 없습니다. 전체 기능이 필요하면 반드시 Edit 탭에서 시작하세요.

제출제출 체크리스트

  • Paint(Erase)로 부분 교체한 이미지 1장 (실습 1)
  • Smart Select로 배경만 교체한 이미지 1장 (실습 2)
  • Retexture로 스타일 전환한 이미지 1장 (실습 3)
  • 원본과 편집본을 나란히 비교한 캡처
  • 파일명: 이름_에디터실습.png 형식으로 저장
