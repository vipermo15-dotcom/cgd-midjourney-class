포트폴리오-활용프롬프트·레퍼런스-실습가이드·리텍스처-실습가이드를 먼저 끝낸 뒤 진행하세요.
기준: Midjourney v8.2(이미지) + Google Veo / Gemini Omni(영상)

Concept이 자료가 다루는 것

광고 콘텐츠 제작의 7개 실무 분야(인쇄출판·브랜드디자인·굿즈디자인·편집디자인·SNS마케팅·퍼포먼스마케팅·숏폼콘텐츠제작) 각각에 대해, 하나의 소재를 3가지 질감 스타일로 제안하는 이미지 프롬프트 세트를 제공합니다. SNS·퍼포먼스·숏폼 3개 분야는 실제 영상 제작까지 이어지도록 Veo·Omni 영상 프롬프트도 함께 수록했습니다.

질감 스타일 프레임워크 — 나노바나나 vs 덕트테이프 vs v8 표준

같은 소재를 3가지 톤으로 빠르게 제안하면, 클라이언트에게 "여러 방향을 탐색한 디자이너"라는 인상을 줄 수 있습니다.

스타일성격키워드언제 쓰나
나노바나나따뜻하고 유기적, 천연 소재감organic, natural, handcrafted, warm, fine micro-texture비건·친환경·라이프스타일·수공예 톤
덕트테이프쿨하고 엣지 있음, 도시적industrial, urban, edgy, structured, tape-strip texture테크·스트리트·스포츠·도시적 톤
v8 표준범용적, 사실적 톤clean commercial photography, standard studio lighting표준 비교안이 필요할 때

Veo vs Omni — 영상 프롬프트 작성법이 다릅니다

도구작성 방식특징
Google Veo처음부터 상세한 영화적 지시[촬영기법]+[피사체]+[행동]+[배경]+[스타일] 공식, 4~8초, 대사는 큰따옴표
Gemini Omni대화하듯 단계적으로 지시"감독이 배우에게 지시하듯" 짧은 문장을 이어가며 발전, 턴당 약 10초

Guide실습 순서

  1. 01
    관심 있는 분야 2~3개를 골라 나노바나나·덕트테이프·v8 표준 3버전을 모두 생성합니다.
  2. 02
    세 결과를 나란히 배치하고, 어떤 텍스처가 해당 프로젝트에 가장 적합한지 근거를 한 줄로 적습니다.
  3. 03
    SNS·퍼포먼스·숏폼 분야는 Veo·Omni 영상 프롬프트도 함께 실습하고, 두 도구의 결과 차이를 비교합니다.
  4. 04
    완성한 이미지·영상에 타이포그래피·카피를 편집 툴에서 얹어 최종 포트폴리오 페이지로 마무리합니다.

Tip팁 & 주의사항

  • 나노바나나/덕트테이프는 특정 브랜드 전용 스타일이 아니라 재사용 가능한 질감 프레임워크입니다. "따뜻한 유기적 톤"과 "차가운 산업적 톤"이라는 두 축으로 빠르게 방향을 탐색할 때 활용하세요.
  • Veo·Omni는 미드저니와 별도의 서비스입니다. 이미지는 미드저니로, 영상은 Veo/Omni로 제작한 뒤 최종 편집 단계에서 하나의 톤으로 합쳐 완성하세요.
  • Veo는 대사·사운드까지 프롬프트 안에서 직접 지정할 수 있지만 한 번에 상세하게 써야 합니다. Omni는 대화하듯 여러 번 수정하며 다듬는 방식이 잘 맞습니다.
  • 퍼포먼스 마케팅용 소재는 실제 A/B 테스트를 전제로 하므로, 카피(CTA)가 들어갈 여백을 반드시 프롬프트에 명시하세요.
  • AI로 생성한 이미지·영상은 초안입니다. 최종 로고·정확한 카피·브랜드 컬러 보정은 편집 툴에서 직접 완성하세요.

제출제출 체크리스트

  • 7개 분야 중 3개 이상 선택, 각 3버전(나노바나나/덕트테이프/v8 표준) 완성
  • SNS·퍼포먼스·숏폼 중 1개 이상 분야에서 Veo·Omni 영상 프롬프트 실습
  • 각 결과에 "제안 근거" 한 줄씩 작성
  • 최종 1개 이상은 타이포그래피 합성까지 완료
